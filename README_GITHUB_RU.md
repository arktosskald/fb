# Сеть Зоны 0.36 BETA1 — GitHub Pages

1. Создайте репозиторий для сайта и загрузите в него всё содержимое папки GitHubPages, включая snorkgram, snorkgram-server.json и .nojekyll. Файлы должны лежать в корне репозитория, а не в дополнительной папке.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. После публикации скопируйте адрес сайта из Pages.
4. В игре откройте F&B → Инструменты → Адрес сети Зоны и вставьте полный HTTPS-адрес с папкой репозитория. Пустое поле возвращает локальную копию.

Адрес обычно выглядит как https://ИМЯ.github.io/РЕПОЗИТОРИЙ/. Можно указать свой домен. В конфигурацию входит только адрес сервера SnorkGram.

Одинаковые HTML работают в аддоне и на GitHub Pages. Фотографии, стили и поиск включены; внешние библиотеки и CDN не требуются. Переключение RU/EN ведёт на ту же страницу другого языка. Для проверки вне игры можно открыть index.html; рекомендуемый способ — локальный HTTP-сервер или GitHub Pages.

Портал, справочники и четыре сайта заказчиков открываются в обычном браузере. Кнопка в карточке открывает конкретный заказ из F&B внутри игры. Условия и принятие заказа остаются в ноутбуке. Остальные 32 сервиса каталога работают в ноутбуке. При обновлении существующего сайта сохраните ваш snorkgram-server.json, если адрес сервера уже настроен. Страница SnorkGram открывает отдельно запущенный сервер из комплекта. Чтобы выдать всем посетителям адрес по умолчанию, внесите его в поле server_url файла snorkgram-server.json. Указывайте HTTPS-адрес корня своего сервера. При пустом поле игрок вводит адрес сам. Учётные записи и сообщения хранит сервер SnorkGram. GitHub Pages обслуживает статические страницы портала.

Редакционные исходники: QA/network031_content.py и исходные каталоги аддона. Генератор: QA/build_network031.py; статические стили и поведение — NetworkSite/site.css, site.js и snorkgram.js. Кнопки игровых сервисов передают только идентификатор разрешённого раздела или заказа.

Лицензии фотографий: images-sources.json и credits.html. Файлы фотографий сохранены без изменений; разметка использует кадрирование только при отображении. Сохраните авторство при публикации.
